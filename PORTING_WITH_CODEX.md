# Linux i386 port and Codex

The Linux i386 port in this repository was developed in collaboration with
OpenAI Codex.

Codex assisted with the source-code analysis, debugging, implementation, and
verification of the port.  This included the ELF cold-start path, integration
with the system garbage collector, fixes for modern C and libc behaviour, and
the reproducible clean build.

The original Russell compiler and runtime remain the work of their original
authors.  This notice refers only to the Linux i386 porting work added to this
repository in 2026.
